# Aura Workspace Prototype

Build a polished, responsive front-end prototype for “Aura Workspace,” a modern SaaS productivity dashboard for workplaces. Use the user’s exact specified palette: Light Stone #EFEDE8 as primary canvas/cards/sidebar; Cocoa #39190F typography/structural contrast; Dusty Rose #E5CBCC sparingly themed areas; Soft Blue #D3E0DF secondary UI/borders/inactive states; Soft Lime #E1E2C3 success/tags/hover highlights; Tera Cotta #DB9E83 only main CTAs/critical alerts. Fixed left sidebar with minimalist abstract soft-edged spark/overlapping-shape logo in Soft Blue + Dusty Rose and text Aura, nav: Dashboard, Task Planner, Research, Meeting Notes, Focus Sessions. Create dashboard modules for AI Task Planner/Scheduler (daily/weekly schedule, urgency/importance tags, AI time optimization suggestions, prompt templates, editable outputs), AI Research Assistant (paste input, summarize/key insight/recommendation cards, simplify complex toggle, editable outputs), Meeting Notes Summarizer (raw notes input, extracted editable Key points/Decisions/Action items, assigned person/deadline badges, prompt templates, and a multi-turn workplace assistant chat UI), plus Focus Sessions. Include supportive polished Chief-of-Staff microcopy, generous whitespace, 12-16px radius, subtle hover transitions, full mobile/tablet/desktop responsiveness, and a highly visible Responsible AI Disclaimer footer/banner. Make UI interactive locally (navigation/view switches, tabs/toggles, editable text areas, prompt buttons, chat send simulation) but do not require backend/auth.
